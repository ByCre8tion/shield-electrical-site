# Shield Electrical website

Astro static site, hosted on Firebase Hosting (project `shield-electrical-az`).
Design rules live in `DESIGN.md`. Content lives in `src/data/site.ts` (search for TODO).

- `npm run dev`: local preview
- Push to `main`: GitHub Actions fetches and optimizes photos, builds, and deploys to https://shield-electrical-az.web.app once the `FIREBASE_SERVICE_ACCOUNT` secret is set.

Placeholders to replace before launch: phone, license number, year founded, Shield's own Google reviews and profile link, social links, BBB seal code, real project photos, Jason's story, careers details.
